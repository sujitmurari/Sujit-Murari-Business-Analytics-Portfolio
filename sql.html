AIRLINE PRICING PROJECT · QUERIES 01–03
✈️ Airline Revenue Analysis
QUERY_01 — REVENUE BY ROUTE
Which routes generate the most revenue?
-- Total revenue and average ticket price grouped by route SELECT route, COUNT(*) AS total_flights, SUM(ticket_price) AS total_revenue, ROUND(AVG(ticket_price), 2) AS avg_ticket_price, ROUND(SUM(ticket_price) * 100.0 / SUM(SUM(ticket_price)) OVER(), 2) AS revenue_share_pct FROM flights WHERE travel_class IS NOT NULL GROUP BY route ORDER BY total_revenue DESC LIMIT 10;

QUERY_02 — BOOKING WINDOW PRICE ANALYSIS
How does advance booking affect ticket pricing?
-- Average price by booking window bucket using CASE WHEN SELECT CASE WHEN days_before_travel BETWEEN 0 AND 7 THEN '0–7 days (Last Minute)' WHEN days_before_travel BETWEEN 8 AND 14 THEN '8–14 days' WHEN days_before_travel BETWEEN 15 AND 30 THEN '15–30 days (Optimal)' ELSE '30+ days (Early Bird)' END AS booking_window, COUNT(*) AS bookings, ROUND(AVG(ticket_price), 0) AS avg_price, ROUND(AVG(seat_availability_pct), 1) AS avg_seat_availability FROM flights GROUP BY booking_window ORDER BY avg_price DESC;

QUERY_03 — CLASS-WISE REVENUE BREAKDOWN
Compare economy vs business class revenue contribution
-- Revenue per class with proportion and yield per seat WITH class_revenue AS ( SELECT travel_class, COUNT(*) AS bookings, SUM(ticket_price) AS total_revenue, AVG(ticket_price) AS avg_price FROM flights GROUP BY travel_class ), total AS ( SELECT SUM(total_revenue) AS grand_total FROM class_revenue ) SELECT cr.travel_class, cr.bookings, cr.total_revenue, ROUND(cr.total_revenue * 100.0 / t.grand_total, 1) AS revenue_pct, ROUND(cr.avg_price, 0) AS yield_per_seat FROM class_revenue cr, total t ORDER BY cr.total_revenue DESC;
E-COMMERCE PROJECT · QUERIES 04–06
🛒 Flipkart Revenue Analysis
QUERY_04 — REVENUE BY CATEGORY
Which product categories drive platform revenue?
-- Revenue proxy: selling_price × estimated_sales volume SELECT category, COUNT(*) AS product_count, ROUND(AVG(selling_price), 0) AS avg_price, ROUND(AVG(discount_pct), 1) AS avg_discount_pct, SUM(selling_price * num_reviews * 10) AS revenue_proxy, ROUND(AVG(rating), 2) AS avg_rating FROM flipkart_products WHERE selling_price IS NOT NULL AND num_reviews > 0 GROUP BY category ORDER BY revenue_proxy DESC;

QUERY_05 — DISCOUNT vs RATING CORRELATION
Does higher discount lead to lower product ratings?
-- Average rating per discount bucket — quality perception vs. discount depth SELECT CASE WHEN discount_pct < 10 THEN '<10% (Premium Pricing)' WHEN discount_pct BETWEEN 10 AND 30 THEN '10–30% (Moderate)' WHEN discount_pct BETWEEN 30 AND 50 THEN '30–50% (Heavy Discount)' ELSE '50%+ (Clearance)' END AS discount_band, COUNT(*) AS products, ROUND(AVG(rating), 2) AS avg_rating, ROUND(AVG(num_reviews), 0) AS avg_reviews FROM flipkart_products WHERE rating IS NOT NULL AND discount_pct IS NOT NULL GROUP BY discount_band HAVING COUNT(*) > 50 ORDER BY avg_rating DESC;
QUERY_06 — BRAND PREMIUM INDEX
Which brands command a price premium over category average?
-- CTE to calculate brand premium vs category average price WITH category_avg AS ( SELECT category, AVG(selling_price) AS cat_avg_price FROM flipkart_products GROUP BY category ), brand_avg AS ( SELECT brand, category, AVG(selling_price) AS brand_avg_price, COUNT(*) AS sku_count FROM flipkart_products GROUP BY brand, category HAVING COUNT(*) >= 20 ) SELECT b.brand, b.category, b.sku_count, ROUND(b.brand_avg_price, 0) AS brand_avg_price, ROUND(c.cat_avg_price, 0) AS category_avg_price, ROUND((b.brand_avg_price / c.cat_avg_price) * 100, 1) AS premium_index FROM brand_avg b JOIN category_avg c ON b.category = c.category ORDER BY premium_index DESC LIMIT 15;
GYM ANALYTICS PROJECT · QUERIES 07–08
💪 Gym Member Retention Analysis
QUERY_07 — RETENTION RATE BY WORKOUT TYPE
Which workout types lead to highest 90-day retention?
-- 90-day retention rate by workout type and session frequency SELECT workout_type, sessions_per_week, COUNT(*) AS total_members, SUM(CASE WHEN retention_days >= 90 THEN 1 ELSE 0 END) AS retained_90d, ROUND( SUM(CASE WHEN retention_days >= 90 THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 1 ) AS retention_rate_pct FROM gym_members GROUP BY workout_type, sessions_per_week ORDER BY retention_rate_pct DESC;

QUERY_08 — PEAK HOUR DISTRIBUTION
When do members check in? Identify capacity bottlenecks.
-- Check-in distribution by hour with running total (window function) SELECT EXTRACT(HOUR FROM check_in_time) AS hour_of_day, CASE WHEN EXTRACT(HOUR FROM check_in_time) BETWEEN 5 AND 9 THEN 'Morning' WHEN EXTRACT(HOUR FROM check_in_time) BETWEEN 10 AND 16 THEN 'Afternoon' WHEN EXTRACT(HOUR FROM check_in_time) BETWEEN 17 AND 21 THEN 'Evening' ELSE 'Night' END AS time_slot, COUNT(*) AS checkins, ROUND( COUNT(*) * 100.0 / SUM(COUNT(*)) OVER(), 1 ) AS pct_of_daily, SUM(COUNT(*)) OVER (ORDER BY EXTRACT(HOUR FROM check_in_time)) AS running_total FROM gym_checkins GROUP BY hour_of_day, time_slot ORDER BY hour_of_day;

QUERY_09 — PRODUCTIVITY MULTIPLIER BY DEPARTMENT
Which departments benefit most from AI tools?
-- Average productivity multiplier and hours saved by department SELECT department, COUNT(*) AS employees, ROUND(AVG(productivity_multiplier), 2) AS avg_productivity_x, ROUND(AVG(hours_saved_per_week), 1) AS avg_hours_saved, ROUND(AVG(adoption_score), 1) AS avg_adoption_score, ROUND( AVG(hours_saved_per_week) * 52 * 800 -- ₹800/hr avg / NULLIF(AVG(training_investment), 0) , 1) AS annual_roi FROM ai_productivity GROUP BY department ORDER BY avg_productivity_x DESC;
